# security-requirements


## Sobre

Este projeto apresenta uma análise dos requisitos de segurança do sistema acadêmico fictício de uma escola.

## Aplicação

O sistema é utilizado por alunos, professores e administradores para consultar e gerenciar informações acadêmicas, notas, faltas e documentos.

## Objetivo

Identificar requisitos que podem melhorar a segurança da aplicação e reduzir possíveis riscos para os alunos, admin e professores principalmente
